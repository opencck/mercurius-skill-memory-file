# Устройство MEMORY.md

Два раздела. Заголовки узнаются на трёх языках: `## Правила` / `## Rules` / `## 规则` и `## Заметки` / `## Notes` /
`## 笔记`; другие заголовки внутри раздела (`### Код`, `### Сейчас`) остаются частью этого раздела.

```markdown
## Правила
- Отвечать коротко, без вступлений.
- Перед действием на серверах — спрашивать.
- Отчёты — таблицей, суммы в рублях.

## Заметки
### Сейчас
- Переезд сайта на новый сервер (до 25.11).
### Как работать
- По утрам — сводка дел, без подробностей.
```

- **Правила** — то, что сказано прямо («всегда», «никогда», «не надо», «больше так не делай»), в том числе о формате и
  тоне. В промпт идут указаниями и целиком, даже если файл больше предела. Сжимаются только формулировки, не смысл.
- **Заметки** — остальное: дела в работе со сроками, договорённости, полезное для следующих бесед. Сделанное и
  прошедшее уходит первым; устойчивые знания о людях, проектах и серверах переносятся в память фактов. Если файл
  больше предела, обрезаются заметки — с конца.

Текст до первого из этих заголовков и файл без них считаются заметками.

## Как сокращать строку

| Было | Стало |
|------|-------|
| «Владелец несколько раз просил, чтобы я писал ему покороче и не начинал с приветствий» | «Отвечать коротко, без приветствий.» (в правила) |
| Три строки о формате отчётов в разных местах | Одна строка в правилах |
| «12.11 договорились до 15.11 подготовить отчёт» (уже 20.11, отчёт сдан) | убрать |
| «У Ивана сервер web-1 на Debian 12» | `memory_propose`, из файла убрать |

## Что считается

Предел — в знаках, не в токенах; считаются тексты обоих разделов без заголовков. Шапка заметок в промпте показывает,
сколько из предела занято; точное число для своего файла — `run_command` с `wc -m MEMORY.md`.
