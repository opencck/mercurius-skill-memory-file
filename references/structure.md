# Устройство MEMORY.md

Короткий файл, который легко сжимать: строки по одной мысли, разделы по назначению, самое важное — в начале (если
файл больше предела, в промпт попадает именно начало).

## Разделы

```markdown
# Память

## Правила
- Отвечать коротко, без вступлений.
- Перед действием на серверах — спрашивать.

## Как работать
- Отчёты — таблицей, суммы в рублях.
- По утрам — сводка дел, без подробностей.

## Сейчас
- Переезд сайта на новый сервер (до 25.11).

## Заметки
- Пароли — только через /secret, не в чат.
```

- **Правила** — то, что собеседник сказал прямо («всегда», «никогда», «не надо»). Первым разделом: даже обрезанный
  файл их сохранит. Сжимаются только формулировки, не смысл.
- **Как работать** — предпочтения формата, тона, порядка. Повторы объединяются.
- **Сейчас** — дела в работе со сроками. Сделанное и прошедшее уходит первым.
- **Заметки** — остальное. Устойчивые знания о людях, проектах и серверах отсюда переносятся в память фактов.

## Как сокращать строку

| Было | Стало |
|------|-------|
| «Владелец несколько раз просил, чтобы я писал ему покороче и не начинал с приветствий» | «Отвечать коротко, без приветствий.» |
| Три строки о формате отчётов в разных местах | Одна строка в «Как работать» |
| «12.11 договорились до 15.11 подготовить отчёт» (уже 20.11, отчёт сдан) | убрать |
| «У Ивана сервер web-1 на Debian 12» | `memory_propose`, из файла убрать |

## Что считается

Предел — в символах, не в токенах; считается весь файл с заголовками и разметкой. Длину проверяй после записи:
`read_file` показывает текст, а точное число — `run_command` с `wc -m MEMORY.md`.
