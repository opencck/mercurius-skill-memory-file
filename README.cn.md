# mercurius-skill-memory-file

[Mercurius](https://github.com/opencck/mercurius) 的内置技能：智能体如何让 `MEMORY.md`（参与者的、项目的或某个场所的，如群组、频道、话题）保持整洁并控制在上限之内，以及什么内容放在哪里。该文件有两个部分：「Rules」（规则），作为指令完整放入提示词；「Notes」（笔记），作为参考资料放入，超过 `MEMORY_FILE_LIMIT`（默认 4000 个字符）的部分会被截掉。达到上限的 85 % 起，提示词会要求压缩该文件。该技能指示智能体：读取整个文件、做一份快照、合并重复内容、删除已完成或过时的内容、把长期知识移入事实记忆、一次调用把文件重写到上限的 70–80%、检查其长度并说明做了什么——绝不丢弃规则，也不把规则移到笔记中，并且在尝试两次后停止，而不是循环往复。

该技能的文本是俄语，即智能体的默认语言。

## 内容

| 文件 | 说明 |
|------|------------|
| `SKILL.md` | 何时压缩、工作顺序、不该做什么 |
| `references/structure.md` | 精简版 `MEMORY.md` 的各个部分、如何缩短一行、长度如何计算 |
| `BRIEF.md` | 本仓库的规格说明（俄语） |

## 使用

该技能是 Mercurius 的子模块 `skills/memory-file`，启动时作为内置技能加载；当提示词说 `MEMORY.md` 超过上限时，智能体用 `skill_view` 打开它。其格式——带有 `SKILL.md` 的文件夹——
是智能体技能的通用格式。
