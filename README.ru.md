# mercurius-skill-memory-file

Встроенный скилл [Меркурия](https://github.com/opencck/mercurius): как агент держит `MEMORY.md` участника в пределе.
Файл целиком идёт в промпт личного чата участника — до `MEMORY_FILE_LIMIT` символов (по умолчанию 8000); больше —
только начало и пометка. Скилл велит агенту прочитать файл целиком, снять снимок, объединить повторы, убрать
сделанное и устаревшее, перенести устойчивые знания в память фактов, перезаписать файл одним вызовом до 70–80%
предела, проверить длину и коротко сказать, что сделано, — не удаляя правил, которые участник сказал сам, и
останавливаясь после двух попыток, а не по кругу.

Текст скилла — на русском, языке агента по умолчанию.

## Состав

| Файл | Что это |
|------|---------|
| `SKILL.md` | Когда сжимать, порядок работы, чего не делать |
| `references/structure.md` | Разделы компактного `MEMORY.md`, как сокращать строку, как считается длина |
| `BRIEF.md` | Спецификация этого репозитория |

## Использование

Скилл — сабмодуль `skills/memory-file` Меркурия; при старте загружается как встроенный, агент открывает его через
`skill_view`, когда в промпте пометка о переполнении `MEMORY.md`. Формат — папка с `SKILL.md` — общий для скиллов
агентов.
